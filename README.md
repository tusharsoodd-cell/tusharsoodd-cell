# Tushar Sood

I build things at the intersection of markets and machines — quant research tooling, low-latency systems, and agent infrastructure.

## What I'm working on

- **diffuse** — information diffusion in markets: directed lead-lag networks between ETFs (transfer entropy + Granger), shock-propagation simulation, walk-forward out-of-sample testing with a null model
- **orderbook** — limit order book + matching engine in C++, ~2M events/sec, fuzz-tested against an independent reference
- **honest-backtester** — event-driven backtester where rigor is the feature; includes a leak-toggle demo showing one bar of look-ahead inflating Sharpe from -0.48 to +12.46
- **agentdom** — AI-first web page representation: compact, actionable semantic trees for browser agents (11/11 agent tasks answerable vs 2/11 for raw HTML)
- **quiet-reader** — local-first Chrome extension for calm reading and private annotations
- **bulk-youtube-transcriber** — bulk YouTube transcription with local Whisper
